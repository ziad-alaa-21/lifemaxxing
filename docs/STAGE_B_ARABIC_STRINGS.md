# قاموس نصوص المرحلة الثانية (Stage B Strings - Egyptian Colloquial Arabic)

ملف المراجعة الخاص بنصوص اللهجة المصرية العامية لشاشات الجسم (Body) والذهن (Mind).  
**قواعد الصياغة:**
- لغة عامية مصرية طبيعية وسلسة ومفهومة للشباب والرياضيين في مصر.
- كلمات واضحة ومباشرة:
  - "Mind score (from your logs)" -> "درجة ذهنك (من تسجيلاتك)" (بدون أي ذكر لمصطلح Cognitive)
  - "Bedtime and wake time" -> "ميعاد النوم والصحيان" (بدون Circadian)
  - "Insights" -> "ملاحظات" / "تحليلات" (بدون Cognitive Insights)
  - "Sleep score (from your log)" -> "درجة النوم (من تسجيلك)" (بدون ترجمة ككفاءة أو Sleep Score مجردة)
  - ممنوع منعاً باتاً: `telemetry`، `circadian`، `cognitive`، `ultradian`.
- المصطلحات الدارجة في الجيم المصري:
  - `reps` -> **عدات**
  - `plates` -> **طارات**
  - `sets` -> **مجموعات**
  - `barbell` -> **البار**
  - `+20 each side` -> **+20 كل ناحية (+40 كجم الإجمالي)**
